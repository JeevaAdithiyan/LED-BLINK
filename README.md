# Arduino LED Blink

A basic Arduino project demonstrating LED control using a digital output pin.

## Components Used

- Arduino board
- LED
- 220Ω resistor
- Breadboard
- Jumper wires

## How It Works

The Arduino configures the LED pin as an output.

The LED is turned ON for 1 second and then OFF for 1 second repeatedly, creating a continuous blinking effect.

## Concepts Learned

- Digital output
- pinMode()
- digitalWrite()
- delay()
- Basic Arduino programming
- Basic circuit connections
